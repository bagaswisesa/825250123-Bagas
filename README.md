# Tripzap - Home & Home Two (React + Bootstrap lokal, tanpa CDN)

Jalankan:
    npm install
    npm run dev      # development
    npm run build    # hasil build ada di folder dist/

Halaman (diakses lewat menu dropdown "Home"):
- Home     (Our Premier Boats)        -> #/
- Home Two (Boats and Yacht Rental)   -> #/home-two

Gambar: taruh di public/images/ sesuai nama pada DAFTAR-GAMBAR.md
(shared/, home/, home-two/). Gambar yang belum ada tampil sebagai placeholder gradient.

Logo: ganti file public/images/shared/logo.png dengan logomu sendiri (dipakai di navbar dan footer).

Pertemuan 13: footer 4 kolom + bagian CTA di atas footer (components/Cta.jsx, Footer.jsx), tombol scroll-up di kiri (ScrollTopButton.jsx), tombol chat di kanan dengan modal Bootstrap (ChatButton.jsx). CSS ada di src/styles/main.css (file eksternal).
