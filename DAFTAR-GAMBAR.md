# Daftar Gambar

Taruh foto kamu di `public/images/` **dengan nama file persis seperti di bawah** (huruf kecil, format `.jpg`, timpa file placeholder yang ada).
Kalau ada file yang belum kamu ganti, bagian itu otomatis tampil gradient biru (tidak error).

Ukuran adalah rekomendasi (px). Tidak harus persis, yang penting rasionya mirip; gambar otomatis di-crop (`object-fit: cover`).

Catatan: `Home` = Our Premier Boats (ada form pencarian). `Home Two` = Boats and Yacht Rental (ada booking card).
